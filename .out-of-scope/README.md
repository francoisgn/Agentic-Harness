```markdown
- **Asked in:** <issue or PR links, every time it came up>
- **Decision:** declined on <date>
- **Why:** <which test of SCOPE.md it fails, in two sentences>
- **What would change the answer:** <the observed failure or design that would make it pass>
```

Before proposing something, search this folder. Reopening a declined idea is welcome when the last line is met.
