# Triage test feedback

References: `.harness/docs/METHODOLOGY.md` §3–§4 (otherwise `${CLAUDE_PLUGIN_ROOT}/docs/METHODOLOGY.md`), taxonomy
`.harness/labels.json` + `.github/labels.local.json`.

1. **Split** the feedback into atomic points (one behaviour, one screen, one expectation). Give each a short
   reference `[Prefix + n]` (prefix: $ARGUMENTS, or the initial of the tab / area).
2. **Duplicates**: for each point, search open and closed issues (titles, bodies, synonyms). A duplicate → comment
   on the existing issue with the new case instead of creating one; a closed issue that comes back → reopen it or
   open a linked one, depending on the project.
3. **Labels** for each point: one type, the tab / area if the project has any, one priority (`priority: critical`
   data loss or crash, `priority: high` wrong or blocking, `priority: medium`, `priority: low`), one difficulty
   (`difficulty: trivial` local and specified, `difficulty: easy` several files / state, `difficulty: medium` engine,
   rules, architecture, `difficulty: hard` frontier tier; if it spans several layers, split it into lots), one status
   (`status: needs-triage`, or `status: needs-decision` if a product decision is missing: say which one in the issue).
   A label missing from the label files → add it to the file first.
4. **Show the plan to the operator before creating anything** (table: ref, point, labels, possible duplicate):
   creating issues is visible to everyone.
5. After approval: create the **umbrella issue** (`type: epic` + the highest priority among its points), title
   `Feedback <date or version>`, with the table `| Ref | Point | Lot | Issue | PR |`; then **one issue per point**,
   title `[Ref] Tab: subject`, body: `### Summary`, finding, expected, screenshots, sources; attach it as a sub-issue
   of the umbrella; copy its number into the table.
6. Propose a grouping into **lots** (issues that touch the same files or need the same model tier) and fill the Lot
   column. Every comment ends with the footer `---` / `_Generated by [Claude Code](https://claude.ai/code)_`.
